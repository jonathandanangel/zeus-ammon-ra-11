## Offline workflow (ZEUS NUMEROLOGY)

1. Clone https://github.com/clcreuso/the-babel-library and authenticate Codex CLI.
2. Translate a legal EPUB with this glossary referenced in the translate prompt.
3. Extract passages from the translated EPUB.
4. Paste keywords into NUMEROLOGY → Babel Secret Library (locate / generate books).
5. Combo books already expand seeds via `babel-library-companion.ts` (glossary-style expansions).

> Not a clone of Basile’s Library of Babel. The companion translates EPUBs; ZEUS locates
> educational 29-letter pages client-side and deep-links libraryofbabel.info.
